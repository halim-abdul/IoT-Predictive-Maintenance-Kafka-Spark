# Dataset documentation

All included examples are generated, not actual plant telemetry. Generator outputs records with UTC timestamps; temperature (°C), vibration (mm/s), pressure (bar), rotational speed (rpm), operating hours and synthetic event label. Machine IDs are pseudonymous.

A real deployment needs written data-sharing approval, calibration records, documented collection interval, asset age and operating conditions, observed breakdown/repair dates, failure definition, missing-data audit, censoring handling, maintenance interventions and train/test isolation by site and asset.

Do not interpret the simulated failure field as a real measured outcome.
